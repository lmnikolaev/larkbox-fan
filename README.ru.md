# larkbox-fan

**Управление вентилятором мини-ПК Chuwi LarkBox (Celeron J4115) в Linux.**

[English version](README.md)

В Linux вентилятор LarkBox ведёт себя непредсказуемо: может работать после установки, а после перезагрузки больше не включаться, или наоборот крутиться всё время. Этот пакет возвращает поведение как в Windows: **включается выше 55 °C, выключается ниже**. Без модулей ядра и без изменений в BIOS.

## Как это работает (коротко)

Работающего контроллера вентилятора в BIOS LarkBox нет. Вместо этого вентилятор включается и выключается **внутри ACPI-метода, который сообщает температуру датчика DPTF `SEN4`**. Каждый раз, когда система читает эту температуру, прошивка сравнивает температуру процессора с 55 °C и переключает вывод GPIO, управляющий вентилятором.

- **Windows:** служба Intel DPTF опрашивает датчик каждые несколько секунд, и вентилятор работает как термостат.
- **Linux:** ядро видит `SEN4` как тепловую зону, но никогда её не опрашивает, и вентилятор застывает в состоянии, в котором был при последнем чтении.

`larkbox-fan` — маленькая служба systemd, которая читает температуру `SEN4` каждые 5 секунд. Больше ничего не нужно.

Полный разбор таблиц ACPI — в [docs/acpi-analysis.md](docs/acpi-analysis.md) (на английском).

## Требования

- Chuwi LarkBox (Celeron J4115). Другие модели Chuwi на Gemini Lake тоже могут подойти, см. [Другие модели](#другие-модели).
- Debian 13 и новее, Ubuntu 23.04 и новее или другой дистрибутив на основе Debian с systemd 253+.

## Быстрая установка

Одна команда скачивает последний релиз и устанавливает его:

```sh
curl -fsSL https://raw.githubusercontent.com/lmnikolaev/larkbox-fan/main/install.sh | sudo sh
```

Скрипт проверяет модель, скачивает `.deb` со страницы [Releases](https://github.com/lmnikolaev/larkbox-fan/releases/latest), убирает старую самодельную службу `larkbox-fan.service` (если она есть) и ставит пакет через `apt`. Перед запуском его можно [прочитать](install.sh), он короткий. Если `curl` не установлен, сначала выполни `sudo apt install curl`.

## Установка вручную

1. Скачай `larkbox-fan_1.0-1_all.deb` на странице [Releases](https://github.com/lmnikolaev/larkbox-fan/releases/latest).
2. Установи его:
   ```sh
   sudo apt install ./larkbox-fan_1.0-1_all.deb
   ```
3. Проверь, что служба работает:
   ```sh
   systemctl status larkbox-fan
   ```
   Должно быть `active (running)` и строка журнала вида `Polling /sys/class/thermal/thermal_zone2/temp every 5s` (номер зоны у тебя может быть другим).

Служба запускается автоматически при каждой загрузке.

> **Уже есть самодельная служба с тем же именем?** Сначала удали её:
> ```sh
> sudo systemctl disable --now larkbox-fan
> sudo rm /etc/systemd/system/larkbox-fan.service
> sudo systemctl daemon-reload
> ```

### Без пакета

В дистрибутиве не на основе Debian скопируй два файла из `src/` и включи службу:

```sh
sudo install -Dm755 src/larkbox-fan /usr/libexec/larkbox-fan/larkbox-fan
sudo install -Dm644 src/larkbox-fan.service /usr/lib/systemd/system/larkbox-fan.service
sudo systemctl daemon-reload
sudo systemctl enable --now larkbox-fan
```

Если systemd старше версии 253, удали из файла службы строку `ConditionFirmware=`.

## Проверка

Дай процессору нагрузку и прислушайся к вентилятору:

```sh
for i in 1 2 3 4; do yes > /dev/null & done   # включить нагрузку
watch -n2 'grep -H . /sys/class/thermal/thermal_zone*/temp'
pkill yes                                      # снять нагрузку
```

Вентилятор должен включиться примерно через 5 секунд после того, как температура процессора (`x86_pkg_temp` / `TCPU`) превысит 55 °C, и выключиться вскоре после остывания.

Датчик `SEN4` всегда показывает **26850** (26,85 °C). Это нормально: датчик фиктивный, важен только побочный эффект его чтения.

## Настройка

Изменить интервал опроса (по умолчанию 5 с):

```sh
sudo systemctl edit larkbox-fan
```

```ini
[Service]
Environment=LARKBOX_FAN_INTERVAL=2
```

Порог 55 °C зашит в BIOS, этим пакетом его не изменить.

## Удаление

```sh
sudo apt remove larkbox-fan
```

## Безопасность

- Служба только **читает** файл в sysfs. Она ничего не пишет в регистры оборудования и ничего не может повредить.
- Она работает от непривилегированного временного пользователя в «песочнице» (`ProtectSystem=strict`, без сети и без доступа к домашним папкам).
- Она запускается только на компьютерах, у которых в SMBIOS модель начинается с `LarkBox`, и тихо завершается, если зоны `SEN4` нет.
- Чтение `/sys` не обращается к диску.

## Другие модели

Другие мини-ПК Chuwi на Gemini Lake (LarkBox Pro, Herobox и другие), вероятно, используют тот же приём в BIOS, но это не проверялось. Проверить свой компьютер:

```sh
grep -H . /sys/class/thermal/thermal_zone*/type    # есть ли зона SEN4?
cat /sys/class/dmi/id/product_name                  # как называется модель?
```

Если зона `SEN4` есть, чтение её `temp`, когда процессор горячее 55 °C, должно включить вентилятор. Если это работает, но модель называется не `LarkBox…`, создай issue, и условие запуска службы будет расширено.
